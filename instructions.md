To run this prototype on a macOS machine, follow these steps:

### 1. Prerequisites (Install Node.js)
Make sure you have **Node.js** installed on your macOS.
* You can check if it's installed by running `node -v` and `npm -v` in the macOS Terminal app.
* If not installed, download and install the LTS version from the official [Node.js website](https://nodejs.org/), or install it via [Homebrew](https://brew.sh/) by running:
  ```bash
  brew install node
  ```

### 2. Open Terminal and Navigate to the Project Folder
Open the **Terminal** app on your Mac and use the `cd` command to navigate to the root directory of your copied/cloned project folder:
```bash
cd /path/to/RakanSales\ C4
```

### 3. Install Dependencies
Run the package manager to download and install the required dependencies specified in [package.json](file:///c:/Users/justi/Documents/VeecoTech/Rakansales/Antigravity/RakanSales%20C4/package.json):
```bash
npm install
```

### 4. Start the Development Server
Run the local dev server using:
```bash
npm run dev
```

### 5. View the App
Once started, the console will output a local URL (typically `http://localhost:5173`). Cmd+Click that link or copy it into Safari/Chrome to view and interact with the prototype.
