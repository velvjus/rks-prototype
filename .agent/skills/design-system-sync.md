name: design-system-sync
description: Ensures that all newly created UI components are automatically documented on the visual guidelines page.
---

### Goal
Keep the `/design-system` route as an accurate, living document that reflects 100% of the UI components used in the project.

### Instructions
- Whenever you create, modify, or import a new UI component or module (e.g., a new Kanban card style, metric widget, or data table variant), you must immediately update the `/design-system` route.
- Add an interactive example of the new component to the guidelines page.
- Ensure the new component is showcased in its various states (default, hover, active, disabled).
- Never consider a component task "complete" until it is successfully rendering and audited on the design system page in both Light and Dark modes.
